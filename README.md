# Personal Portfolio Archive 🚀

> A static personal portfolio website serving as an early exploration into web design and front-end development.

## 📖 Overview

This repository contains the source code for my very first personal portfolio website. Built primarily with **HTML** and **CSS**, this project was a foundational stepping stone that helped me grasp the basics of user interfaces, static asset management, and web structure before moving on to more complex software engineering and algorithmic problem-solving.

While this project is no longer actively updated, it remains here as a time capsule of my initial steps into the tech world.

## ✨ Features

* **Static Layout:** A straightforward, clean design built without modern heavy frameworks.
* **Custom Styling:** Extensive use of raw CSS for layout structuring and visual design.
* **Media Gallery:** Integration of images and visual assets to showcase early work.
* **Minimal JavaScript:** Lightweight scripting for basic interactions.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and content routing.
* **CSS3:** Core styling, animations, and typography (`webfonts`).
* **JavaScript:** Minimal logic for UI enhancements.
